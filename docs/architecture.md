# Architecture Overview

This repository is designed as a layered educational system.

## Layers

1. Foundation layer: terminal, Git, Python, and developer workflow
2. Theory layer: math, probability, data engineering, and ML
3. Model layer: neural networks, deep learning, transformers, and LLMs
4. Systems layer: RAG, agents, APIs, tools, and deployment
5. Production layer: testing, observability, scaling, evaluation, and safety

## Design goals

- Beginner-friendly progression
- Strong practical exercises
- Real project-based learning
- Multi-language implementation guidance
- Agent-assisted instruction support

## Documentation website

The website is implemented in `website/` using Next.js and Tailwind CSS. It provides:

- lesson navigation
- curriculum browsing
- glossary and cheatsheets
- project library
- search and section organization

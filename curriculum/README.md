# Curriculum Overview

This directory contains the core learning roadmap for the course.

## Phase map

- Phase 00 — Computer and Developer Foundations
- Phase 01 — Python Programming
- Phase 02 — Mathematics for AI
- Phase 03 — Data Engineering
- Phase 04 — Machine Learning
- Phase 05 — Deep Learning
- Phase 06 — Neural Networks from Scratch
- Phase 07 — Computer Vision
- Phase 08 — Natural Language Processing
- Phase 09 — Transformers
- Phase 10 — LLMs from Scratch
- Phase 11 — LLM Application Engineering
- Phase 12 — RAG and Vector Search
- Phase 13 — Agent Engineering
- Phase 14 — Tools, APIs and MCP
- Phase 15 — Fine-tuning
- Phase 16 — Multimodal AI
- Phase 17 — Evaluation and Safety
- Phase 18 — AI Infrastructure and Production
- Phase 19 — Capstone Projects

## Curriculum philosophy

The curriculum is deliberately structured around building intuition before optimization. It starts with tools, then programming, then math, then data, then models, then systems, and finally deployment.

## Planned lesson coverage

The repository is designed to scale to approximately 442 lessons across the full curriculum. The actual lesson content in this repository is scaffolded with representative, production-quality examples that follow the full lesson template.

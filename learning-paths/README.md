# Learning Paths

The repository provides multiple paths for different learner goals.

## 1. Complete Beginner to AI Engineer

- Prerequisites: none
- Study time: 9–12 months
- Outcomes: foundation in Python, math, ML, LLMs, systems, deployment

## 2. Python Developer to ML Engineer

- Prerequisites: Python basics, scripting, Git
- Study time: 4–6 months
- Outcomes: data pipelines, ML modeling, evaluation, deployment

## 3. Mathematics to Deep Learning

- Prerequisites: high-school algebra and calculus
- Study time: 3–5 months
- Outcomes: math intuition, backpropagation, model optimization

## 4. Deep Learning to LLM Engineer

- Prerequisites: deep learning fundamentals
- Study time: 3–4 months
- Outcomes: transformers, LLM training, inference, prompting

## 5. LLM Application Engineer

- Prerequisites: Python and API familiarity
- Study time: 2–3 months
- Outcomes: prompts, tools, structured output, production apps

## 6. RAG Engineer

- Prerequisites: embeddings and Python
- Study time: 2–3 months
- Outcomes: chunking, retrieval, ranking, evaluation, search systems

## 7. AI Agent Engineer

- Prerequisites: LLM app engineering
- Study time: 2–4 months
- Outcomes: memory, planning, orchestration, human approval, tool use

## 8. AI Infrastructure Engineer

- Prerequisites: Python, Linux, Docker
- Study time: 3–5 months
- Outcomes: serving, scaling, monitoring, cloud deployment

## 9. AI Research Engineer

- Prerequisites: ML and math fundamentals
- Study time: 4–6 months
- Outcomes: experimentation, evaluation, model understanding, research workflows

## 10. Advanced AI Systems Engineer

- Prerequisites: prior ML/LLM experience
- Study time: 4+ months
- Outcomes: production AI systems, orchestration, observability, reliability

## Recommended course flow

1. Foundations and Python
2. Math for AI
3. Data engineering
4. ML
5. Deep learning
6. Neural networks from scratch
7. Transformers and LLMs
8. RAG, tools, and agents
9. Evaluation and production
10. Capstones

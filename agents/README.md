# Agent Skills and Tutor Instructions

This directory contains reusable educational and operational prompts for AI coding agents.

## Purpose

Support pair-programming, guided learning, and technical mentorship using structured instructions.

## Example skill areas

- debugging
- code review
- project scaffolding
- algorithm reasoning
- research synthesis
- lesson writing

## Suggested usage

Use these skills to build AI-assisted learning experiences that explain both the what and the why behind each concept.

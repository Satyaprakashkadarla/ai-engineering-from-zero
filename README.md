# AI Engineering from Zero

A complete open-source educational platform for learning AI engineering from absolute zero to advanced production systems.

## What this repository includes

- Structured 20-phase curriculum for beginner-to-advanced AI engineering
- Hands-on lessons with concepts, code, exercises, quizzes, and debugging guidance
- Multi-language implementation guidance for Python, TypeScript, and Rust
- Learning paths for different career goals
- Project library with starter-to-solution patterns
- Practice and interview systems with machine-readable JSON
- Glossary and cheatsheets for fast reference
- Modern documentation website built with Next.js and Tailwind CSS
- Agent-oriented learning resources and reusable skill templates

## Why this curriculum is different

This repository focuses on first-principles understanding: the learner starts with hardware, software, math, data, and engineering workflow; then advances to ML, deep learning, LLMs, RAG, agents, and production deployment.

The learning experience includes:

- GitHub markdown lessons
- a searchable documentation website
- runnable code examples and projects
- AI-agent tutoring templates and reusable skills

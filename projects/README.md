# Projects

This directory contains a project library for hands-on learning.

## Structure

Every project includes:

- README.md
- docs/
- starter/
- solution/
- tests/
- evaluation/
- assets/

## Example projects

- personal-ai-assistant
- ml-prediction-system
- document-rag-assistant
- mini-gpt
- mcp-server

## Project progression

Projects are intentionally staged from beginner to advanced.

The starter code remains intentionally incomplete with TODO markers, while the solution code demonstrates a complete reference implementation.

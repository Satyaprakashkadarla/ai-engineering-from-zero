# Contributing

This repository is an educational and open-source project. Contributions should improve learning quality, correctness, and production readiness.

## Contribution principles

- Teach from first principles
- Prefer clarity over hype
- Keep code examples runnable and documented
- Make lessons beginner-friendly but technically accurate
- Add testing, validation, and debugging guidance
- Prefer strong educational structure over shallow summaries

## Lesson standards

Every lesson should follow a consistent educational format:

- title
- overview
- learning objectives
- prerequisites
- conceptual explanation
- real-world applications
- mathematical foundations when relevant
- implementation from scratch
- production implementation
- practical exercises
- beginner/intermediate/advanced challenges
- quiz with answers and explanations
- debugging guidance
- further reading

## Project standards

Each project should include:

- README
- docs
- starter code
- solution code
- tests
- evaluation rubric
- assets

## Types of contribution

- New curriculum phases or lessons
- Fixes to existing code examples
- Additional exercises or challenge sets
- Glossary entries and cheatsheets
- Website improvements
- Agent skill templates
- Evaluation and benchmarking resources

## Workflow

1. Open an issue for major changes
2. Create a branch
3. Add or update lesson materials
4. Validate docs and project structure
5. Submit a pull request with a clear rationale

## Style guide

- Prefer plain-English explanations
- Use clear headers and minimal jargon
- Provide examples with code fences and short explanations
- Link concepts to real-world systems
- Document assumptions and limitations
